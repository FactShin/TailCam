The dashboard updates dependencies flagged by the existing npm audit while
preserving React 18, the dashboard routes, and its browser compilation target.
The Python package continues to include the built dashboard; users do not need
Node.js to run TailCam.

## Dependency changes

| Package | Previous | Updated |
|---|---|---|
| Vite | 5.4.21 | 6.4.3 |
| React Vite plugin | 4.3.3 | 4.7.0 |
| Vite PWA plugin | 0.20.5 | 1.3.0 |
| React Router DOM | 6.30.6 | 7.18.3 |

The inherited audit reported six vulnerable package entries: one high and five
moderate. Vite/esbuild findings concern development-server behavior; the
packaged FastAPI dashboard does not run that server. The router upgrade includes
a fix for malformed navigation targets. TailCam uses declarative `BrowserRouter`,
so the separate server-rendered hydration advisory does not describe its current
rendering path. These distinctions limit the exposure claim, not the need to
maintain patched dependencies.

## Compatibility

- Dashboard development and builds require Node.js 22 or newer, matching the
  existing Node 22 CI and Docker build. The Python runtime requirement is unchanged.
- React stays on 18.3.1. The compiler target remains unchanged; this patch does
  not introduce a new browser-support promise.
- The service worker must retain network-only handling for API, camera streams,
  recordings, and peer proxy requests. Cached application assets support offline
  navigation without caching footage or API responses.
- No configuration, database, stored footage, model, or node-protocol migration
  is introduced. Runtime, dashboard, and extension version metadata move together
  to 1.8.6.
